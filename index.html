The engineering is the shell around the model.

Harness 不是更长的 prompt。它是工具、权限、记忆、技能、编排和验收回路。这份报告对照 Claude Code、Cowork、Design、Duet、Codex、OpenCode、DeepSeek Harness、Grok Build、Grok Bot、Hermes 与 Muse。

A harness is not a longer prompt. It is tools, permissions, memory, skills, orchestration, and a check that can fail. This report reads Claude Code, Cowork, Design, Duet, Codex, OpenCode, DeepSeek Harness, Grok Build, Grok Bot, Hermes, and Muse against that definition.

Stars are a GitHub API snapshot from 2026-10-27, not a ranking. Live X search was unauthenticated, so community practice is cited from public repos and vendor essays.

Anthropic 点名三种失效：做到一半就收工，给自己的结论打高分，压缩之后忘掉“不要做 X”。动态工作流的意义，是给子任务一块干净的上下文。

Anthropic names three failures: stopping early, preferring your own findings, and losing “do not do X” after compaction. Dynamic workflows exist to give a subtask a clean context.

案例

Cases

Claude Code

ANTHROPICCODE

终端、IDE、桌面、Web 共用引擎。CLAUDE.md 与 MCP 跨表面。2026-06 的动态工作流用 agent()、parallel()、pipeline() 写任务专用 harness，可隔离到 worktree。失败模式写进了公开文章。

One engine across terminal, IDE, desktop, and web. Dynamic workflows, June 2026, compose agent(), parallel(), and pipeline(), with worktree isolation. The failure modes are public.

Claude Cowork

WORK

口语里的 “Claude Work” 更接近它：在选定文件夹和工具里把活做到可审查的文件。合上电脑继续，可定时。删除要批准。企业权限可进 SIEM。

The closest thing to “Claude Work”: finish the job in chosen folders and tools, leave a reviewable file, keep going with the laptop closed. Deletes need approval.

Claude Design

DESIGN

从真实组件和设计系统出图，画布上改，/design-sync 接回 Claude Code。可导出到 Adobe、Canva、Figma 以外的 Gamma、Lovable、Miro、Replit、Vercel、Wix。独立站开放到 2026-12-14。

Builds from real components, edits on canvas, and hands back to Claude Code with /design-sync. Connectors include Adobe, Canva, Gamma, Lovable, Miro, Replit, Vercel, and Wix.

Claude Duet

PROACTIVE

2026-10-21 研究预览。早上简报，只在需要判断时打扰，人离开后继续。凭证沿用 Managed Agents，自动模式沿用 Claude Code。6,000+ 连接器。人从盯终端改为例外处理。

Research preview, 2026-10-21. Morning brief, interrupt only for judgment, continue while you are away. Credentials follow Managed Agents. The human handles exceptions.

Codex

131,021 ★RUST

本地 CLI、IDE、桌面 codex app、云端 Codex Web。Apache-2.0。贡献是停留时间：人看着的仓库，和人离开后的仓库，是同一代理的两种门。

Local CLI, IDE, desktop app, and Codex Web. Apache-2.0. The contribution is dwell time: the same agent, two doors, depending on whether you stay.

OpenCode

221,881 ★MIT

build 全权限，plan 默认不改文件。Tab 切换。权限被做成了两种代理，而不是一段提醒。

build has full access. plan refuses edits. Tab switches. Permission is a persona, not a reminder.

DeepSeek Harness

262,467 ★CORDIS

一切皆插件。对话里可以写插件并安装。工作区、技能、子代理、定时、审批都是一等对象。仍是开发者预览，会破坏兼容。本报告写于这个运行时里。

Everything is a plugin, including writing a plugin from chat. Workspace, skills, subagents, schedules, approvals. Developer preview, breaking changes expected. This report was written inside it.

Grok Build

XAIACP

TUI、headless、ACP。可挂任意模型。grok inspect 列出技能、插件、hooks、MCP。技能文件夹与 Claude 生态同形。

TUI, headless, and ACP. Bring any model. grok inspect lists skills, plugins, hooks, and MCP. Skill folders match the emerging standard.

Grok Bot

CLOUD COMPUTER

有名字的队友，共用一台云电脑：浏览器、文件、终端。可互发消息、移交任务、把演示存成技能。合上笔记本继续。共享电脑意味着账号内 bot 都能看见放上去的登录态。

Named teammates on one shared cloud computer. They message, hand off work, and save a demonstrated path as a skill. The laptop can close. Shared logins are visible to every bot on the account.

Hermes Agent

257,343 ★NOUS

学习回路是产品：从经验写技能，跨会话记忆，SOUL.md，20+ 消息平台，具名 bot，定时，多种终端后端包括 Daytona 和 Modal。

The learning loop is the product: skills from experience, cross-session memory, SOUL.md, 20+ chat platforms, named bots, cron, and terminal backends from Docker to Modal.

Muse Code

METASANDBOX ON

首次运行即沙箱和批准。交互或 muse exec。工作流与子代理分开，生命周期最多 1,000 个子任务。本地会话之间可以交接和请求审查。

Sandbox and approvals from the first run. Interactive or muse exec. Workflows are separate from subagents, capped at 1,000 child tasks. Live sessions can hand off and request review.

ECC 与控制面

289,613 ★

ECC、planning-with-files、claude-mem 优化记忆与规范。cc-switch、Orca、OpenHands 优化舰队。它们不替代上面的产品，它们管理那些产品。

ECC, planning-with-files, and claude-mem optimize memory and norms. cc-switch, Orca, and OpenHands optimize the fleet. They manage the products above. They do not replace them.

该抄的，不该抄的

What to copy

展开

Fan out

迁移、审计、不稳定复现、多视角评审。每个假设一块干净上下文，另一路代理按量规挑错。Claude Code、Muse、DeepSeek teams、Grok Bot 群聊都在做这件事。

Migrations, audits, flaky bugs, multi-perspective review. One clean context per hypothesis, and a second agent grading against a rubric.

折叠

Fold

一个函数、一块紧耦合的补丁。Anthropic 2026-10-22 写过：更少的子代理，加上渐进披露，往往又好又便宜。小改动不要上工作流。

A function, or a tightly coupled patch. Anthropic’s October 2026 note: fewer subagents plus progressive disclosure is often better and cheaper.

最小清单

Minimum loop

先沙箱，再一个会失败的验收命令，再短规则文件，再技能文件夹，再磁盘计划。对外发送、删除、凭证单独批准。

Sandbox first. Then a check that can fail. Then a short rule file, skill folders, and a plan on disk. Separate approval for sends, deletes, and credentials.

两条路线

Two bets

DeepSeek 把壳做成插件系统。Hermes 把壳做成学习回路。Grok Bot 把壳做成云电脑。Claude 把壳拆成 Code、Cowork、Design、Duet，共用判断和安全分类器。

DeepSeek makes the shell a plugin system. Hermes makes it a learning loop. Grok Bot makes it a cloud computer. Claude splits it into Code, Cowork, Design, and Duet, sharing judgment and safety classifiers.
